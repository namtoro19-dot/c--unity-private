## Giải thích các khái niệm Git cơ bản (Bài 1)
- git clone: Sao chép toàn bộ mã nguồn và lịch sử của repository trên GitHub về máy cá nhân.
- git commit: Lưu lại một bản chụp (snapshot) các thay đổi mã nguồn trên máy cục bộ kèm thông điệp mô tả.
- git push: Đẩy các commit từ máy cá nhân lên repository trên GitHub.
- git pull: Tải và gộp các thay đổi mới nhất từ repository trên GitHub về máy cá nhân.
